Before processing or saving any data, the system must display a structured preview table showing all detected records from the CSV.

✔ Center Name
✔ Region
✔ Cluster
✔ Center Code / Format (e.g. 1.1)

* Correct cluster mapping
* No duplicate or incorrect entries
* Proper formatting before permanent upload
